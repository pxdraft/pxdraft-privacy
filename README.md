# pxdraft privacy policies

Privacy policy pages for pxdraft apps, served with GitHub Pages at https://pxdraft.github.io/pxdraft-privacy/

| App | Page | Source of truth |
| --- | --- | --- |
| Moodly | https://pxdraft.github.io/pxdraft-privacy/moodly/ | `docs/privacy/index.html` in `pxdraft/moodly` |

To add an app, create a folder with an `index.html` and link it from the root `index.html`.
